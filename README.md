# STACK learning portal

Portal version 0.3.1 · 7 October 2026

https://gitzhacode.github.io/STACK/

Original ellipse dome display studies. Elastica and robotics use baked 3D animations with orbit, zoom, spin, start/stop, reset and timeline seeking. They start automatically when opened. Rounded render meshes and sampled visual states are included; source CAD, fitting/IK solvers and robot execution instructions are excluded. The 30-second guided tour plays the baked animations. The original project film remains in Further reading.

Educational desktop plugins remain 0.1.0. Graphics runtime: Three.js and OrbitControls, MIT; vendor/THREE-LICENSE.txt.
